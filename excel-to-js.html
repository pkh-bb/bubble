엑셀 → Bubble 백업 변환기

텍스트, 사진, ARTIST 답장, 투표, 음성 메시지를 data.js로 변환합니다. 파일은 브라우저에서 처리됩니다.

엑셀 파일을 선택하세요.

메시지 종류별 입력

  1. 투표: type을 poll, 질문은 text, 선택지는 options 열에 선택지1;선택지2;선택지3 형식으로 입력
  2. 음성: type을 audio, 파일 경로를 src, 재생 길이를 duration에 입력 (예: 00:18)
  3. 사진/음성 파일은 GitHub 저장소의 assets 폴더에 먼저 올리세요.

투표 득표수/실제 투표 상태는 현재 변환 데이터에 포함되지 않습니다. 음성은 사이트에서 브라우저 기본 재생기로 재생됩니다. 변환하려면 인터넷 연결이 필요합니다.
